# Словарь ульпана

Локальное приложение на React, TypeScript и Vite.

```sh
npm install
npm run dev
```

Открой адрес, который покажет Vite. Для проверки сборки: `npm run build`.

## Данные

Источник словаря — `src/dictionary.json`. Дата в `updatedAt` записывается в формате `ГГГГ-ММ-ДД` и меняется вручную при обновлении словаря. В `sections` находятся названия тем (`title`), необязательные пояснения (`note`) и записи (`entries`): иврит (`hebrew`), произношение (`pronunciation`) и перевод с пояснениями (`meaning`). Текст `intro` отображается внизу страницы. Файл Markdown автоматически не читается и не обновляется.

Для записи можно добавить поле `hebrewWithNiqqud` с проверенным написанием с огласовками. `hebrew` сохраняет обычное написание без огласовок. Если поле отсутствует, приложение показывает `hebrew` в обоих режимах. Предпочтение переключателя сохраняется в localStorage браузера.
